# ORION 0.6.0 — Premium UI

Beş yeni gradient mövzusu, canlı rəng önizləməsi və masaüstü/mobil ekranlar
üçün yenilənmiş Ayarlar bölməsi.

## Yükləmək

GitHub-da **Code → Download ZIP** seç. Arxivi aç, proqram fayllarını mövcud
ORION qovluğuna köçür. Öz `.env`, `.venv` və şəxsi məlumatlarını saxla.
Proqramı əvvəlcə sistem panelindən tam bağla, sonra `START.bat` və ya
`START_BROWSER.bat` ilə yenidən aç.

- [Tam quraşdırma və istifadə](README_AZ.md)
- [0.6.0 yeniləmə qeydləri](RELEASE_NOTES_AZ.md)
- [Gradient və Ayarlar yeniləməsi](GRADIENT_YENILEME_AZ.md)
- [Yoxlama nəticələri və məhdudiyyətlər](YOXLAMA_060_AZ.md)

ayarlarını istifadə et; nümunə `.env.example` faylındadır.
